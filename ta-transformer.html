背景知识：AI 核心术语速览

以下术语将在报告中频繁出现，此处以直观方式简要说明其含义

模型  Model
经过大量数据训练后的"数学函数"。给它输入数据，它输出预测结果。本次演示的 Transformer 就是一个模型。
训练  Training
让模型反复看数据、对答案、改错的循环过程，相当于刷题备考。本项目在 H200 GPU 上训练约 2–3 小时。
神经网络  Neural Network
受大脑神经元启发的计算结构，由多层"权重矩阵"堆叠而成。Transformer 是神经网络的一种。
注意力机制  Attention
模型处理每个位置时，动态决定"重点看哪里"。读一句话时人眼会聚焦关键词，Attention 就是这个过程的数学实现。
Token  Token
序列被切分后的最小处理单元。文本里是词/字，本项目里是光谱图切出的小 patch（15×10 = 150 个）。
参数  Parameters
模型内部可学习的数值，训练过程就是调整这些数值。GPT-4 约 1.8 万亿个；本模型 3800 万个。
损失函数  Loss
衡量预测与真实值差距的数字。训练目标就是让它不断接近 0。Loss 降得越快，训练越顺利。
轮次  Epoch
模型把全部训练数据看完一遍算一个 epoch。本项目训练 300 个 epoch，相当于把 10 万条数据看了 300 遍。
过拟合  Overfitting
模型把训练数据"背下来"，但遇到新数据就失效。类似只背真题、不理解原理，换一题就不会了。

ΔA 信号
\[ \Delta A(\lambda,\, t) = \sum_{i=1}^{N} \underbrace{\bigl[\sigma_i^{\text{ESA}}(\lambda) - \sigma_i^{\text{GSB}}(\lambda)\bigr]}_{\text{光谱形状（与时间无关）}} \cdot \underbrace{n_i(t)}_{\text{浓度动力学}} \]
光谱形状
\[\sigma_i(\lambda) = A_i \exp\!\left(-\frac{(\tilde\lambda - \lambda_i^0)^2}{2w_i^2}\right), \quad \tilde\lambda - \lambda_i^0 = (\lambda-\lambda_i^0)\cdot(1\pm\alpha), \quad \alpha\in[-0.3,\,0.3]\] 非对称 Gaussian；ESA（激发态吸收）为正，GSB（基态漂白）为负
浓度动力学
\[\frac{d\mathbf{n}}{dt} = K^{\!\top}\mathbf{n},\quad K_{ii}=-\!\sum_{j\neq i}k_{ij},\quad \mathbf{n}(0):\ n_A\ge 0.96\] LSODA 求解 ODE；速率按能级分三档： τA∈[0.5, 10] ps  ·  τB∈[12, 200] ps  ·  τC∈[25, 1000] ps

为什么不用传统拟合 / CNN？

三种方法各自的优势与瓶颈

传统全局拟合
人工写出 σ(λ) 高斯参数 + 速率方程
→ Levenberg-Marquardt 求最优解
✓ 物理可解释
✗ 必须先猜物种数
✗ 易陷局部最优
✗ 单条数据 → 数小时
卷积神经网络 (CNN)
用 3×3 / 5×5 局部卷积核
逐层提取局部特征
✓ 速度快
✓ 适合局部纹理
✗ 感受野受限，远距相关性弱
✗ 长寿命物种需跨整张时间轴
Transformer ★
任意两个 patch 之间
都可以"全局对话"
✓ 全局自注意力 ⇒ 捕捉长寿命物种
✓ 单次前向 → 多任务输出
✓ 注意力权重可视化 ⇒ 可解释
· 代价：需要大量训练样本
关键差异：CNN 的卷积核只看附近几个像素；
Transformer 的自注意力让每个 patch 都能直接询问其它 99 个 patch——这正是分辨多种重叠物种所必需的全局视野。

2D 切块嵌入

将 ΔA(150×100) 切成 10×10=100 个 patch，线性投影后叠加可学习 2D 位置编码

src/models/encoder.py — TA2DPatchEmbedding 
class TA2DPatchEmbedding(nn.Module):
    def __init__(self, n_wl=150, n_t=100,
                 patch_wl=15, patch_t=10, d_model=384):
        # 150/15=10 波长块 × 100/10=10 时间块，共 100 个 patch
        self.proj      = nn.Linear(patch_wl * patch_t, d_model)
        self.wl_embed  = nn.Embedding(n_wl // patch_wl, d_model)
        self.t_embed   = nn.Embedding(n_t  // patch_t,  d_model)
        self.cls_token = nn.Parameter(torch.zeros(1, 1, d_model))

    def forward(self, x):  # x: (B, 150, 100) 归一化 ΔA 矩阵
        B = x.shape[0]
        # ① unfold 切块 → 展平 → Linear 投影 → (B, 100, 384)
        patches = x.unfold(1, 15, 15).unfold(2, 10, 10)
        tokens  = self.proj(patches.contiguous().view(B, 100, 150))
        # ② 2D 可学习位置编码（波长轴 + 时间轴各自 embed 后叠加）
        wl = torch.arange(10, device=x.device).repeat_interleave(10)
        t  = torch.arange(10, device=x.device).repeat(10)
        tokens += self.wl_embed(wl) + self.t_embed(t)
        # ③ 拼接 CLS token → 输出 (B, 101, 384)
        cls = self.cls_token.expand(B, -1, -1)
        return torch.cat([cls, tokens], dim=1)
数据形状流转
(B, 150, 100) 原始 ΔA 矩阵
↓ unfold 切块
(B, 10, 10, 15, 10) 10×10 个 15×10 块
↓ 展平 + Linear
(B, 100, 384) 100 个 token
↓ 加 2D 位置编码 + CLS
(B, 101, 384) 送入 Encoder
为什么要 2D 位置编码？
每个 patch 来自二维网格，波长 × 时间两个轴需要分别编码——一维位置丢失了"哪条波长"和"哪个时刻"的物理含义。
CLS token 的角色
可学习的"虚拟 patch"——通过自注意力从其它 100 个 patch 收集信息，最终成为整张光谱的全局摘要。

缩放点积注意力

\[ \text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^{\!\top}}{\sqrt{d_k}}\right)V \]
① 三件套从同一输入投影
Q · K · V 均由同一序列经线性变换得到——这就是自注意力的"自"。
② 缩放防止饱和
除以 \(\sqrt{d_k}=\sqrt{32}\)， 避免大维度下点积过大、softmax 进入饱和区导致梯度消失。
③ CLS 在"四处张望"
CLS 的 \(Q\) 与全部 100 个 patch 的 \(K\) 做点积，
得到的注意力行 = "模型当前在看哪里"。
④ 矩阵 → 热图
注意力矩阵维度 (B, 12, 101, 101)，
取第 0 行 reshape 成 10×10 即可作为热图可视化。

注意力前向传播 — 实际生产代码

src/models/encoder.py — PhysicsAwareAttention.forward() 
def forward(self, x, mask=None):
    B, N, C = x.shape  # B=1, N=101（100 patch + 1 CLS），C=384

    # ① 融合 QKV：单次 Linear(384→1152) 同时得到 Q、K、V，节省显存带宽
    qkv = self.qkv(x).reshape(B, N, 3, self.n_heads, self.d_k)
    q, k, v = qkv.permute(2, 0, 3, 1, 4).unbind(0)  # (B, 12, 101, 32)

    # ② Scaled Dot-Product：点积缩放 → mask（可选）→ softmax → dropout
    attn = (q @ k.transpose(-2, -1)) * self.scale  # (B, 12, 101, 101)
    if mask is not None:
        attn = attn.masked_fill(mask.bool(), float('-inf'))
    attn = self.attn_drop(attn.softmax(dim=-1))       # 训练时随机 dropout

    # ③ 加权聚合 V + 输出投影，恢复 d_model=384 维度
    x = self.proj((attn @ v).transpose(1, 2).reshape(B, N, C))
    return x, attn  # attn 供 TAEncoder 逐层收集 → 可视化热图
Tensor 形状追踪
x  (B, 101, 384) 输入
qkv  (B, 101, 1152)  融合三件套
q,k,v  (B, 12, 101, 32)
attn  (B, 12, 101, 101)  注意力图
out  (B, 101, 384) 同形状返回
为什么 QKV 一起算？
合并成单次 Linear(384→1152) 比拆三个 Linear(384→384) 显存带宽更省，GPU 利用率更高。
为什么 12 个头？
d_model 384 = 12 × 32，每个头独立学习一种"看光谱的视角"——后面的可视化能直观看到不同头关注不同区域。
为什么要返回 attn？
训练时 attn 不参与 loss，但会被 TAEncoder 收集起来，用于可解释性可视化——也就是后面那些热图。
